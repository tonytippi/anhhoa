# Decision: Parent list table-first

Date: 2026-09-24

The reviewed implementation will replace the prior linked-parent presentation in the `Phụ huynh` submenu with a paged, parent-first operational table. The approved surface follows the existing student-list visual language: contact columns, a compact child/class aggregate, and an accessible row action that opens focused parent-link management.

The frozen UX mockup is not edited. `StudentParent` remains the action identity in the focused detail and revocation remains an existing server-authoritative, idempotent operation.
