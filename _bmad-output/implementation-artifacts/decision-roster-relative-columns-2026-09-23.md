# Decision: Roster Relative Columns and Action Menu

**Date:** 2026-09-23

The reviewed roster table is intentionally superseded for this approved change. Its parent-link summary column is replaced by `Mẹ` and `Bố`, projected only from active links with exact relationship labels. Other relationship labels remain visible only in the focused student profile. The final row column uses a compact `...` menu for `Xem hồ sơ` and `Quản lý liên kết người thân`; destructive student actions are excluded.
